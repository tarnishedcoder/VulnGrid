# Security Delivery Lab Handbook

End-to-end showcase of a full Application Security / DevSecOps pipeline:
ingest findings from SAST/SCA/DAST tools, enrich with EPSS, risk-score with
`CVSS × EPSS`, gate pull requests, and auto-create remediation tickets.

Start with:

- [OWASP Top 10](owasp-top10.md) – cheat sheet used by the dashboard
- [CWE Mappings](cwe-mappings.md) – common CWEs produced by the scanners
- [Secure SDLC Checklist](sdlc-checklist.md) – gates and ownership per phase
