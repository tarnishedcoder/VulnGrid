# OWASP Top 10 (2021)

| # | Category | Description |
|---|----------|-------------|
| 1 | **Broken Access Control** | Users can access resources they shouldn't. |
| 2 | **Cryptographic Failures** | Weak or missing encryption. |
| 3 | **Injection** | SQL, OS command, NoSQL, etc. |
| 4 | **Insecure Design** | Missing security design patterns. |
| 5 | **Security Misconfiguration** | Default credentials, open ports. |
| 6 | **Vulnerable & Out-of-Date Components** | Use of libraries with known CVEs. |
| 7 | **Identification & Authentication Failures** | Weak password policies, session fixation. |
| 8 | **Software & Data Integrity Failures** | Untrusted libraries, supply-chain attacks. |
| 9 | **Security Logging & Monitoring Failures** | No audit trails, no alerts. |
| 10 | **Server-Side Request Forgery (SSRF)** | Untrusted URLs are fetched by the server. |

> The dashboard visualises any finding that maps to these categories using the CWE ID.
